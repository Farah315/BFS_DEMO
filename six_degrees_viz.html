Real Facebook friendship graph (McAuley & Leskovec, NIPS 2012). No simulation. No synthetic data. Pick any two nodes and watch BFS find the actual shortest path.

The Full Dataset

The original file facebook_combined.txt contains 4,039 people and 88,234 real friendships. Measured directly: average shortest path = 3.693, diameter = 8. Remarkably close to Facebook’s official figure on 1.59 billion users (4.57 links / 3.57 intermediaries, 2016).

The visualization below is a real subgraph (95 nodes, 344 friendships) sampled around an actual shortest path of length 5. Every edge and every distance is 100% real.
